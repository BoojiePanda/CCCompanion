# CC Companion

CC Companion shares selected Class Codex character preferences across World of Warcraft characters while keeping specialization-specific choices separate.

## Features

- Shares selected Class Codex window and panel preferences across characters
- Remembers collapsed sections for stats, talents, rotation, enchants, and gems
- Preserves specialization-specific content, source, hero talent, stat, rotation, trinket, crafting, and talent-pane choices
- Restores the appropriate Class Codex selections after login and specialization changes
- Keeps specialization data separated by stable specialization ID
- Ignores unsupported Class Codex fields instead of copying the entire database
- Does not modify Class Codex files

## Important

Class Codex by Icy Veins is required and must be installed and enabled. CC Companion has no separate settings window because it captures and restores supported Class Codex preferences automatically.

## Installation

1. Download the zip file and unarchive it.
2. Place the `cccompanion` folder inside:

   `World of Warcraft/_retail_/Interface/AddOns/`

3. Ensure it is properly installed by checking:

   `World of Warcraft/_retail_/Interface/AddOns/cccompanion/cccompanion.toc`

4. Enable Class Codex and CC Companion from the AddOns menu on the character-selection screen.
5. Log in or type `/reload`.
